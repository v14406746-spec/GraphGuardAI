1. EXECUTIVE SUMMARY & VIDEO OBJECTIVES
--------------------------------------------------------------------------------
This document provides a turnkey, timestamped script, visual stage directions, 
voiceover lines, and demonstration workflows for recording a winning demonstration 
video for FalkorDB Hackathon Track 1.

Key Selling Points to Demonstrate in the Video:
  1. Connected Data Agent: The agent doesn't guess; it explores graph topologies
     using Cypher queries across users, IPs, devices, sessions, and servers.
  2. Model Context Protocol (MCP): 8 standardized MCP tools allow the agent
     to dynamically query FalkorDB graph context on-demand.
  3. Adaptive Multi-Hop Traversal: The agent begins at 3 hops, evaluates evidence
     sufficiency, expands to 5 hops if inconclusive, and continues to 8 hops
     if a threat trail leads to critical crown-jewel infrastructure.
  4. Deterministic 8-Factor Risk Scoring: Mathematical, explainable risk calculation
     grounded in verified graph facts—eliminating LLM hallucination.
  5. Counterfactual "What-If" Engine: Read-only simulation testing hypothetical 
     risk reductions without mutating the production database.
  6. Human-in-the-Loop Governance: Tiered autonomous policy actions backed by
     human analyst sign-off and an append-only SOC audit log.
  7. Production Ready & Live Deployed: Full-stack FastAPI + React app running live
     on Vercel with 11/11 automated tests passing.
